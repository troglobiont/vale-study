# Valja Study · v0.13.1

Приложение с математикой, английским и природой и обществом: задания по площади (стр. 8–28) и словарник Smiles 4 (Freska, 2022). Русский, сербский (кириллица), английский. Компактный переключатель **ру / ср / en**, сине-голубая палитра по цветам Finder.

## Использование и установка

Кнопка **«Установить»** открывает выбор платформы. Для Android подготовлен отдельный APK с учебником внутри. Для iPad подготовлен Xcode-проект; установочная версия требует подписи Apple и пока не опубликована. Подробности и команды сборки — в [mobile/README.md](mobile/README.md).

Ниже — дополнительный способ использовать веб-версию:

- **iPad:** Safari → «Поделиться» → «На экран “Домой”» → оставить включённым «Открывать как веб-приложение» → «Добавить».
- **Android:** Chrome → кнопка «Установить приложение», когда браузер её предлагает, либо меню ⋮ → «Установить приложение» / «Добавить на главный экран».

При первом открытии дождитесь загрузки материалов: на странице установки появится сообщение о готовности работы без интернета. Учётная запись приложению не нужна. Данные ответов и черновики хранятся на устройстве; между iPad и Android история не синхронизируется.

## Английский

Вкладка «Английский»: 156 слов и выражений из десяти тем Smiles 4 с русским и сербским переводом и номерами страниц. Это словарник к курсу, а не полный перенос упражнений учебника. Учебник, тетрадь и электронный демоурок доступны по ссылкам издателя.

Повторение — до восьми карточек за подход. Сначала вспомнить значение, затем раскрыть перевод и выбрать самооценку: «Ещё раз» возвращает слово через 10 минут, «Трудно» — через сутки, «Знаю» увеличивает интервал до 1, 3, 7, 14, 30 дней. Просроченные карточки идут перед новыми. Сессию можно продолжить после закрытия приложения. Повторение происходит при открытии, push-уведомлений нет.

В «Мои слова» можно добавить до 300 своих слов с переводами и необязательной прямой HTTPS-ссылкой на аудиозапись. Слова, даты повторения и сессия входят в локальное сохранение и JSON-экспорт вместе с математикой; миграция сохраняет прежние ответы и аватарку.

Для всех 156 слов подготовлены отдельные аудиофайлы с британской английской озвучкой. Они воспроизводятся по HTTPS-ссылкам с GitHub Pages, с обычной или сниженной скоростью; в нативный пакет и офлайн-кэш не включаются. Нужен интернет. Голос устройства используется только как запасной способ для собственных слов без аудиоссылки; при недоступности выводится видимая ошибка. Системный SpeechSynthesis для слов учебника больше не требуется: Android WebView его не поддерживает.

61 запись из [официального аудиокаталога](https://freska.rs/smiles-4-audio/) подключена прямыми HTTPS MP3-ссылками к встроенному `<audio>`. Файлы остаются на сервере издателя, не копируются в репозиторий/пакет приложения/CacheStorage. Плеер создаёт запрос только по нажатию, работает с `preload="none"`, показывает ошибку при сбое или 15-секундном ожидании. Браузер может временно буферизовать и HTTP-кэшировать поток. Интернет для этих записей необходим; доступность сервера издателя не контролируется приложением. Все ссылки проверены: HTTP 206, `audio/mpeg`, диапазоны байтов. Это не подтверждает наличие всех записей к рабочей тетради и проверочным заданиям.

## Сохранение и обновление

«Аватарка → Данные и обновления → Обновить сейчас» проверяет версию, загружает обновление и открывает его. Перед переключением состояние сохраняется повторно; незавершённую математику и английские карточки не нужно заканчивать. Веб-версия использует версионный Service Worker; установленная версия — локальный пакет через `@capgo/capacitor-updater` 8.54.2. Приложение продолжает запускаться из файлов на устройстве, `server.url` не используется.

Для Android 0.6.0 и старее нужен один ручной переход на APK 0.7.1 с новым механизмом. После него изменения HTML/CSS/JS и учебных материалов загружаются внутри приложения. Изменение нативных плагинов или системных разрешений по-прежнему требует нового APK / выпуска через Apple. iPad-проект включает тот же механизм, но установочная подпись Apple ещё не настроена.

Метаданные берутся с GitHub Pages (`version.json`), ZIP — из конкретного GitHub Release. Проверяются ID приложения, версия, совместимость нативной оболочки, допустимый адрес архива и SHA-256. Автопроверка при открытии только сообщает о новой версии; загрузка и применение запускаются кнопкой. Статистика и сервис обновлений Capgo отключены; аккаунт Capgo и подписка не нужны. Если обновление не загрузилось или новая версия не подтвердила запуск, остаётся прежняя рабочая версия.

Обновление приложения не синхронизирует пользовательские данные между устройствами. Ответы, словарник, даты повторения и настройки хранятся локально; аватарка хранится отдельно и не входит в JSON-экспорт. Очистка данных браузера/приложения может удалить прогресс. Облачной синхронизации и автоматического импорта пока нет.

### Публикация следующих обычных обновлений

1. Повысить `APP_VERSION` и `mobile/package.json` до одной версии. Для нового APK также повысить Android versionCode и iOS build/version.
2. Из `mobile/`: `pnpm build && pnpm package:update`. Команда создаёт `mobile/update/Vale-Study-update.zip`, SHA-256 и корневой `version.json`.
3. Прогнать тесты. Опубликовать исходники и `version.json` на GitHub Pages, затем создать соответствующий GitHub Release и приложить ZIP с точным именем из манифеста. До загрузки архива обновление новой версии не будет доступно для установки.
4. Проверить, что опубликованный архив совпадает с SHA-256 в манифесте. ZIP не содержит ключей, пользовательских сохранений и аудиофайлов издателя.

Совместимость текущей нативной оболочки: `nativeRuntime: 1`, `minNativeVersion: 0.7.0`. При несовместимых нативных изменениях поднять эти ограничения, подготовить новый установщик и повторно проверить обновление. Доступность метаданных/архива зависит от GitHub; неудачная проверка не удаляет рабочую версию и сохранения.

## Структура

`index.html`, `style.css`, `app.js` — интерфейс; `core.js` — точная проверка на BigInt; `book.json`/`book.js` — фиксированные задания с тремя языками; `assets/` — предоставленные изображения; `manifest.webmanifest`, `sw.js`, иконки — установка и офлайн-ресурсы. Веб-версия работает без npm, сервера ответов и базы данных. Отдельные Android/iOS-проекты и их зависимости находятся в `mobile/`. Закрытых ключей подписи в репозитории нет.

Материалы учебника сохраняют права своих правообладателей. Приложение оцифровывает предоставленные страницы; официальное соответствие программе и независимая школьная вычитка переводов не заявляются.

## Навигация и статистика 0.8

Математика сразу открывает всё содержание: тема «Площадь» и все шесть разделов. Продолжение сохранённого задания — отдельная кнопка с подписью раздела и страницы. У каждого раздела две вкладки: задания и правила. Кнопка «Всё содержание» доступна и внутри задания. Общей дублирующей страницы правил больше нет; старые ссылки продолжают открывать содержание темы.

Статистика имеет общий обзор предметов и отдельные страницы математики и английского. Математика считает решения и первые самостоятельные ответы; английский — слова с самооценкой, текущую очередь повторения и число повторений, включая собственный словарник. Показатели разных предметов не складываются в общий процент. Список предметов используется и для навигации, и для обзора статистики.

Фотография, настройки, экспорт, обновления и удаление локальных данных собраны под аватаркой. Старые ссылки #parent и #updates сохранены. Прогресс, словарник и сохранённые сессии не мигрируются и не сбрасываются. Выпуск 0.8.0 доставляется обычным обновлением интерфейса, без нового APK.

## Проверка слов и грамматика 0.9

Тест — до 5 или 8 слов из последней пачки, уже изучавшихся слов, темы или всего словарника; варианты ответов берутся из существующих переводов. Первый выбор фиксируется, ошибки можно повторить отдельной попыткой. Тесты не меняют интервалы самооценки. Результаты тестов и грамматики показаны отдельно в статистике. Незавершённые тесты сохраняются.

Грамматика: Present Simple и Present Continuous. Два коротких правила и 8 предложений, адаптированных из Smiles 4, Freska 2022, стр. 29, упражнение 4 (пункты 1, 3, 4, 6), и стр. 17, упражнение 3 (пункты 2, 3, 4, 6). Вместо письменного заполнения — выбор формы. Исходные предложения сохранены, варианты ответов и объяснения добавлены для интерактивного формата. Полный курс грамматики не заявляется.

Для имени под значком Android подготовлена нативная версия 0.9.0, versionCode 9, с прежней подписью и идентификатором. Обновление интерфейса и новые тесты доступны через обычное встроенное обновление и в предыдущем установщике 0.7.x; для нового имени значка APK ставится поверх, без удаления приложения.

## Дополнительные тесты по математике 0.10

Во всех шести разделах: Задания / Правила / Тест. Вкладка теста содержит новые, отдельно подготовленные упражнения с другими числами: единицы площади, ары и гектары, прямоугольник, квадрат, прикладные и смешанные задачи. Выбор 5, 8 или 10 вопросов; числовой ввод и A–D. С версии 0.11.0 сложность определяется выбранным уровнем и не повышается в конце теста. Это дополнительные упражнения в рамках тем курса, а не задания из книги.

Пока идёт тест, правильность не раскрывается. Можно листать вопросы, менять ответы и проверить их список перед общей отправкой. «Проверить весь тест» проверяет только полностью заполненный набор с допустимым числовым вводом. Первый результат фиксируется один раз. После проверки неверные вопросы можно пересчитать; успешные исправления учитываются отдельно, не заменяя первый результат. Результаты дополнительных тестов отделены от 149 проверяемых заданий учебника и от английского. Незавершённая попытка, ответы и пересчёты сохраняются локально и включаются в экспорт.

Выпуск 0.10.0 совместим с существующим механизмом обновлений, новый APK для этих функций не нужен.

## Тропа открытий · v0.11.0

В каждом из шести разделов математики три уровня: «Старт» (одно действие, небольшие числа, соседние единицы), «Уверенный шаг» (обратные задачи и два знакомых действия), «Вызов» (смешанные единицы, составные фигуры и прикладные задачи). Выбор 5 / 8 / 10 определяет только длину теста. Даже последний вопрос первого уровня остаётся простым.

За полностью решённый тест, сразу или после пересчёта ошибок, выдаётся один кристалл уровня и открывается следующий. Награда одинакова при любой длине теста. Коллекция содержит 18 кристаллов (6 × 3), доступна в статистике математики, её счётчик — на главной математике. Повторения не дублируют и не отнимают награды. Рейтинга и штрафов за пропуск дней нет.

Правильность скрыта до общей проверки. После неё виден первый результат и путь к исправлению; пересчёт сохраняет исходный балл. Кристаллы, лучшие первые результаты по уровням и незавершённая попытка сохраняются локально и входят в JSON-экспорт. Тесты, начатые до появления уровней, можно закончить без изменения их вопросов; прежние результаты остаются, новые кристаллы за старые тесты не выдаются.

Выпуск работает через «Обновить сейчас» в существующей Android-оболочке; повторно скачивать APK не требуется.

## Мой сад · v0.12.0

Отдельная вкладка «Мой сад»: девять мест на полках, бесплатный папоротник и 18 находок, открывающихся за уже заработанные кристаллы математических тестов. Каждый кристалл открывает следующую находку; кристаллы не тратятся. Растения и украшения можно поставить, переставить, поменять местами и вернуть в коллекцию. Предметы из коллекции не исчезают.

В мастерской кашпо доступны восемь цветов, полоски, горошек и собственная мозаика 6 × 6. Для мозаики есть краски, ластик, отмена мазка и очистка с возможностью отмены. Только кнопка «Сохранить кашпо» применяет рисунок; отмена сохраняет прежнее оформление. Расстановка и рисунки включены в локальное сохранение и JSON-экспорт. Интернет для сада не нужен.

Уже полученные в 0.11.0 кристаллы сразу открывают соответствующие находки. Система английских наград пока не добавлена. Направления развития зафиксированы в [DEVELOPMENT.md](DEVELOPMENT.md).

## Природа и общество · 0.13.0

Третий учебный предмет: «Природа и друштво 4. Радна свеска», Нови Логос, 7-е изменённое издание, 2025, ISBN 978-86-6109-927-4. Все задания из сфотографированного раздела «Моја домовина», стр. 8–50: 103 карточки по 19 темам, 341 поле ответа. В число карточек входят продолжения заданий, проекты, опыт, наблюдение и карта перед итоговыми вопросами. Это не весь учебник: страницы 52+ не предоставлены.

Условия, подписи полей, варианты ответов, таблицы, схемы и служебные сообщения доступны на русском, сербском и английском. Сербский текст оригинала можно раскрыть отдельно. Надписи внутри исходных фотографий остаются частью оригинальных иллюстраций; буквы ребусов и буквенных сеток сохранены для решения исходных головоломок. Форматы: выбор одного/нескольких вариантов, сопоставление через списки, ввод чисел и текста, таблицы, рисунки поверх иллюстраций и свободный рисунок, необязательное фото работы. При включённом рисовании холст принимает палец/стилус; при выключенном можно прокручивать страницу. Фото уменьшается и хранится только локально; не отправляется в GitHub. Фото и штрихи входят в экспорт данных, общий лимит фотографий — около 1,5 МБ для экономии локального хранилища.

139 однозначных полей проверяются автоматически. Открытые объяснения, спорные варианты, карты, опыты и проекты сохраняются для обсуждения со взрослым; ребёнок отдельно отмечает выполнение. Такая отметка в статистике отличается от автоматически верного ответа. Для задания стр. 48 №9 показано замечание о неоднозначности исходника; ключ не выдуман. Некоторые исходные иллюстрации содержат карандашные отметки: они обозначены как часть источника, не как образец ответа.

Прогресс нового предмета находится в `state.nature`; старые ответы, английский и сад сохраняются. Скрипты и иллюстрации включены в веб-кэш и нативный пакет обновления. Новые учебные упражнения и ролевые миссии в этой версии не создавались. Следующий этап зафиксирован в DEVELOPMENT.md.
