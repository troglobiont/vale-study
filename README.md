# Vale Study · v0.7.2

Приложение с математикой и английским: задания по площади (стр. 8–28) и словарник Smiles 4 (Freska, 2022). Русский, сербский (кириллица), английский. Компактный переключатель **ру / ср / en**, сине-голубая палитра по цветам Finder.

## Использование и установка

Кнопка **«Установить»** открывает выбор платформы. Для Android подготовлен отдельный APK с учебником внутри. Для iPad подготовлен Xcode-проект; установочная версия требует подписи Apple и пока не опубликована. Подробности и команды сборки — в [mobile/README.md](mobile/README.md).

Ниже — дополнительный способ использовать веб-версию:

- **iPad:** Safari → «Поделиться» → «На экран “Домой”» → оставить включённым «Открывать как веб-приложение» → «Добавить».
- **Android:** Chrome → кнопка «Установить приложение», когда браузер её предлагает, либо меню ⋮ → «Установить приложение» / «Добавить на главный экран».

При первом открытии дождитесь загрузки материалов: на странице установки появится сообщение о готовности работы без интернета. Учётная запись приложению не нужна. Данные ответов и черновики хранятся на устройстве; между iPad и Android история не синхронизируется.

## Английский

Вкладка «Английский»: 156 слов и выражений из десяти тем Smiles 4 с русским и сербским переводом и номерами страниц. Это словарник к курсу, а не полный перенос упражнений учебника. Учебник, тетрадь и электронный демоурок доступны по ссылкам издателя.

Повторение — до восьми карточек за подход. Сначала вспомнить значение, затем раскрыть перевод и выбрать самооценку: «Ещё раз» возвращает слово через 10 минут, «Трудно» — через сутки, «Знаю» увеличивает интервал до 1, 3, 7, 14, 30 дней. Просроченные карточки идут перед новыми. Сессию можно продолжить после закрытия приложения. Повторение происходит при открытии, push-уведомлений нет.

В «Мои слова» можно добавить до 300 своих слов с переводами и необязательной прямой HTTPS-ссылкой на аудиозапись. Слова, даты повторения и сессия входят в локальное сохранение и JSON-экспорт вместе с математикой; миграция сохраняет прежние ответы и аватарку.

Для всех 156 слов подготовлены отдельные аудиофайлы с британской английской озвучкой. Они воспроизводятся по HTTPS-ссылкам с GitHub Pages, с обычной или сниженной скоростью; в нативный пакет и офлайн-кэш не включаются. Нужен интернет. Голос устройства используется только как запасной способ для собственных слов без аудиоссылки; при недоступности выводится видимая ошибка. Системный SpeechSynthesis для слов учебника больше не требуется: Android WebView его не поддерживает.

61 запись из [официального аудиокаталога](https://freska.rs/smiles-4-audio/) подключена прямыми HTTPS MP3-ссылками к встроенному `<audio>`. Файлы остаются на сервере издателя, не копируются в репозиторий/пакет приложения/CacheStorage. Плеер создаёт запрос только по нажатию, работает с `preload="none"`, показывает ошибку при сбое или 15-секундном ожидании. Браузер может временно буферизовать и HTTP-кэшировать поток. Интернет для этих записей необходим; доступность сервера издателя не контролируется приложением. Все ссылки проверены: HTTP 206, `audio/mpeg`, диапазоны байтов. Это не подтверждает наличие всех записей к рабочей тетради и проверочным заданиям.

## Аватарка

Нажмите круглую аватарку в шапке → «Выбрать фото». Снимок обрезается по центру и уменьшается до 256×256. Фото хранится отдельным локальным ключом, не отправляется на сервер/GitHub и не включается в экспорт результатов. Можно заменить или убрать фото; учебный прогресс сохраняется. Исходный файл в галерее не меняется.

## Учебный блок

151 карточка на основе переданных заданий, без генерации новых упражнений. 149 карточек с автоматической проверкой, 145 числовых полей. Задания со стр. 17 №4 и стр. 20 №2 требуют измерить неподписанный рисунок в бумажной книге: для них проверяется только расчёт по введённым измерениям; они исключены из обычных сессий.

Ответы вводятся целыми числами, выбором знака/варианта, сопоставлением пар и сортировкой карточек. Есть помощь, разбор, исправление, повторение и необязательный черновик пальцем/стилусом. Распознавание почерка не требуется.

## Структура предметов

Верхнее меню: «Математика», «Английский», «Для родителя». В математике сначала каталог тем, сейчас в нём «Площадь». Внутри темы — «Обзор темы» и «Правила», затем шесть разделов с упражнениями. Прежние адреса `#chapter/...`, `#task/...`, `#rules` и сохранённые сессии продолжают работать.

## Сохранение и обновление

«Для родителя → Данные и обновления → Обновить сейчас» проверяет версию, загружает обновление и открывает его. Перед переключением состояние сохраняется повторно; незавершённую математику и английские карточки не нужно заканчивать. Веб-версия использует версионный Service Worker; установленная версия — локальный пакет через `@capgo/capacitor-updater` 8.54.2. Приложение продолжает запускаться из файлов на устройстве, `server.url` не используется.

Для Android 0.6.0 и старее нужен один ручной переход на APK 0.7.1 с новым механизмом. После него изменения HTML/CSS/JS и учебных материалов загружаются внутри приложения. Изменение нативных плагинов или системных разрешений по-прежнему требует нового APK / выпуска через Apple. iPad-проект включает тот же механизм, но установочная подпись Apple ещё не настроена.

Метаданные берутся с GitHub Pages (`version.json`), ZIP — из конкретного GitHub Release. Проверяются ID приложения, версия, совместимость нативной оболочки, допустимый адрес архива и SHA-256. Автопроверка при открытии только сообщает о новой версии; загрузка и применение запускаются кнопкой. Статистика и сервис обновлений Capgo отключены; аккаунт Capgo и подписка не нужны. Если обновление не загрузилось или новая версия не подтвердила запуск, остаётся прежняя рабочая версия.

Обновление приложения не синхронизирует пользовательские данные между устройствами. Ответы, словарник, даты повторения и настройки хранятся локально; аватарка хранится отдельно и не входит в JSON-экспорт. Очистка данных браузера/приложения может удалить прогресс. Облачной синхронизации и автоматического импорта пока нет.

### Публикация следующих обычных обновлений

1. Повысить `APP_VERSION` и `mobile/package.json` до одной версии. Для нового APK также повысить Android versionCode и iOS build/version.
2. Из `mobile/`: `pnpm build && pnpm package:update`. Команда создаёт `mobile/update/Vale-Study-update.zip`, SHA-256 и корневой `version.json`.
3. Прогнать тесты. Опубликовать исходники и `version.json` на GitHub Pages, затем создать соответствующий GitHub Release и приложить ZIP с точным именем из манифеста. До загрузки архива обновление новой версии не будет доступно для установки.
4. Проверить, что опубликованный архив совпадает с SHA-256 в манифесте. ZIP не содержит ключей, пользовательских сохранений и аудиофайлов издателя.

Совместимость текущей нативной оболочки: `nativeRuntime: 1`, `minNativeVersion: 0.7.0`. При несовместимых нативных изменениях поднять эти ограничения, подготовить новый установщик и повторно проверить обновление. Доступность метаданных/архива зависит от GitHub; неудачная проверка не удаляет рабочую версию и сохранения.

## Проверки

458 локальных проверок ядра: правильный, пустой и изменённый ответ для всех 149 автоматически проверяемых карточек, строгий целочисленный ввод, точные большие значения, сохранение первого ответа, помощь и исправления. Фактическая установка на iPad/Honor не выполнялась оператором; PWA подготовлена для добавления пользователем на свои устройства.

```sh
node tests/core.test.cjs
node tests/avatar.test.cjs
node tests/english.test.cjs
node tests/updates.test.cjs
python3 -m http.server 8780 --bind 127.0.0.1
```

Последняя команда запускает локальный просмотр; для установки на планшеты используйте HTTPS-сайт GitHub Pages.

## Структура

`index.html`, `style.css`, `app.js` — интерфейс; `core.js` — точная проверка на BigInt; `book.json`/`book.js` — фиксированные задания с тремя языками; `assets/` — предоставленные изображения; `manifest.webmanifest`, `sw.js`, иконки — установка и офлайн-ресурсы. Веб-версия работает без npm, сервера ответов и базы данных. Отдельные Android/iOS-проекты и их зависимости находятся в `mobile/`. Закрытых ключей подписи в репозитории нет.

Материалы учебника сохраняют права своих правообладателей. Приложение оцифровывает предоставленные страницы; официальное соответствие программе и независимая школьная вычитка переводов не заявляются.
