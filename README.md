# Vale Study · v0.5.0

Приложение с заданиями по площади из предоставленного блока учебника (стр. 8–28). Русский, сербский (кириллица), английский. Компактный переключатель **ру / ср / en**, сине-голубая палитра по цветам Finder.

## Использование и установка

Кнопка **«Установить»** открывает выбор платформы. Для Android подготовлен отдельный APK с учебником внутри. Для iPad подготовлен Xcode-проект; установочная версия требует подписи Apple и пока не опубликована. Подробности и команды сборки — в [mobile/README.md](mobile/README.md).

Ниже — дополнительный способ использовать веб-версию:

- **iPad:** Safari → «Поделиться» → «На экран “Домой”» → оставить включённым «Открывать как веб-приложение» → «Добавить».
- **Android:** Chrome → кнопка «Установить приложение», когда браузер её предлагает, либо меню ⋮ → «Установить приложение» / «Добавить на главный экран».

При первом открытии дождитесь загрузки материалов: на странице установки появится сообщение о готовности работы без интернета. Учётная запись приложению не нужна. Данные ответов и черновики хранятся на устройстве; между iPad и Android история не синхронизируется.

## Аватарка

Нажмите круглую аватарку в шапке → «Выбрать фото». Снимок обрезается по центру и уменьшается до 256×256. Фото хранится отдельным локальным ключом, не отправляется на сервер/GitHub и не включается в экспорт результатов. Можно заменить или убрать фото; учебный прогресс сохраняется. Исходный файл в галерее не меняется.

## Учебный блок

151 карточка на основе переданных заданий, без генерации новых упражнений. 149 карточек с автоматической проверкой, 145 числовых полей. Задания со стр. 17 №4 и стр. 20 №2 требуют измерить неподписанный рисунок в бумажной книге: для них проверяется только расчёт по введённым измерениям; они исключены из обычных сессий.

Ответы вводятся целыми числами, выбором знака/варианта, сопоставлением пар и сортировкой карточек. Есть помощь, разбор, исправление, повторение и необязательный черновик пальцем/стилусом. Распознавание почерка не требуется.

## Сохранение и обновление

История сохраняется локально без персонального профиля, рекламы, трекеров и внешнего AI. Экспорт — JSON в разделе родителя; удаление — с подтверждением. Очистка данных браузера/приложения может удалить прогресс. Автоматический импорт и облачное восстановление отсутствуют.

Веб-версия доступна на iPad и Android. Отдельные пакеты обновляются переустановкой поверх прежней версии или через магазин; описанный ниже механизм относится к веб-версии. Обновления загружаются при открытии с сетью; офлайн-устройство продолжает сохранённую версию. Применение готового обновления предлагается между сессиями. Доставка обновления не означает синхронизацию ответов.

## Проверки

458 локальных проверок ядра: правильный, пустой и изменённый ответ для всех 149 автоматически проверяемых карточек, строгий целочисленный ввод, точные большие значения, сохранение первого ответа, помощь и исправления. Фактическая установка на iPad/Honor не выполнялась оператором; PWA подготовлена для добавления пользователем на свои устройства.

```sh
node tests/core.test.cjs
node tests/avatar.test.cjs
python3 -m http.server 8780 --bind 127.0.0.1
```

Третья команда запускает локальный просмотр; для установки на планшеты используйте HTTPS-сайт GitHub Pages.

## Структура

`index.html`, `style.css`, `app.js` — интерфейс; `core.js` — точная проверка на BigInt; `book.json`/`book.js` — фиксированные задания с тремя языками; `assets/` — предоставленные изображения; `manifest.webmanifest`, `sw.js`, иконки — установка и офлайн-ресурсы. Веб-версия работает без npm, сервера ответов и базы данных. Отдельные Android/iOS-проекты и их зависимости находятся в `mobile/`. Закрытых ключей подписи в репозитории нет.

Материалы учебника сохраняют права своих правообладателей. Приложение оцифровывает предоставленные страницы; официальное соответствие программе и независимая школьная вычитка переводов не заявляются.
