# Word pronunciation

156 separate English pronunciation files matching the fixed vocabulary IDs in english-data.js. Prepared with the British English Daniel speech voice, 145 words/minute, AAC mono 22.05 kHz. These are synthesized word recordings, separate from the publisher’s lesson tracks.

The app streams these files on demand from GitHub Pages. They are excluded from the native update bundle and service-worker pre-cache. Each file was decoded and checked for duration and nonzero signal; audit metadata is in words/index.json.
