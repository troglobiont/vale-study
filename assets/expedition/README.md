# Expedition artwork

desk.png: original text-free decorative artwork generated with the built-in image_gen tool for Valja Study. Palette: sky blue, cobalt, warm cream; paper-craft envelope, toy boat, paper bird and field notebook. The image is not a factual map.

The factual vector map is stored separately in expedition-map.js, generated from public-domain Natural Earth data. See docs/expedition-pilot.md for sources.
